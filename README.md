# Academic website template

A plain HTML/CSS template — no build step, no framework.

## Files

- `index.html` — About / news / contact
- `research.html` — List of papers
- `style.css` — All styling; colors and fonts are set as CSS variables at the top
- `cv.pdf` — CV (linked from `index.html`)
- `headshot.jpg` — a photo of me (linked from `index.html`)
